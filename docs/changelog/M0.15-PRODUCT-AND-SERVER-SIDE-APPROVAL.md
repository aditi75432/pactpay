# M0.15 · Product experience and server-side approval

**Security**
- Pacts are approved through `POST /api/pacts/approve`, stored in `pactpay_pact_approvals`, hashed, and bound to an httpOnly session cookie (`pp_sid`). `/api/paypal/offer-demo/orders` now accepts `approvalId` only. A browser-supplied Pact is refused unless `PACTPAY_ALLOW_CLIENT_PACT=1` (development only).
- The stored Pact hash is re-verified on every load and compared with the order's pact hash.
- `/api/control-center` is scoped to the caller's session by default (`PACTPAY_CONTROL_CENTER_SCOPE=all` to disable).
- In-memory rate limits on search, refresh, evaluate, intent compile, approve, order creation, scenario, settle and explain.
- Session cookie is `Secure` only over HTTPS.

**Product**
- New single-flow experience: Describe, Approve rules, Pick an offer, Hold payment, Result.
- New order screen at `/order/[transactionId]` with plain-English outcomes, before/after table, counterfactual, timeline, receipt and PayPal verification.
- Seller "Demo control" panel replaces the developer scenario selector.
- PayPal return page continues straight to the order screen.
- Optional AI summary of an outcome via `/api/explain` (facts-only guard, deterministic fallback).
- Developer pages moved under a "Developer" menu.

**Core**
- `explainSettlement` (plain-English reasons, changes, counterfactual) and `createRateLimiter`, with tests (93 total).
- `previewChannel3TestQuote` export so the UI shows the exact quote before a hold.
- Fixed the existing `discover/page.tsx` typecheck error.

**Tooling**
- `.env.example`, new README, judge guide, demo script, CI workflow, `scripts/tidy-docs.mjs`.

## M0.15.1 hotfix
- Fixed: a "final total" limit pre-filled from the AI draft made every catalog offer unprovable ("can't confirm yet"), so nothing could be chosen. The home page no longer pre-fills a total unless the shopper asked for one, and a cleared total can no longer come back through the draft.
- Added `applyCheckoutQuote` (pact-core, tested): resolves an *unknown* total-cap result for USD offers using the fixed test quote (item + $4.99 shipping + 8% tax) so the shortlist can show an honest estimate. It never overrides a failed rule, stale or unattributed evidence, or a safety hold, and the settlement gate still re-checks the real total at the end.
- Shortlist: clearer "none of these can be chosen yet" state with next actions.
