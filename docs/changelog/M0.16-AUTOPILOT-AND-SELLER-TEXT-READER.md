# M0.16 · Autopilot and the seller-text reader

**Agentic**
- Autonomy chosen at approval (Ask every time / Ask above a limit / Within my rules), stored server-side with the approved rules (`autonomy_mode`, `autonomy_limit_usd`), never editable afterwards.
- Autopilot: the agent picks the best match, places the hold after a cancellable countdown, re-checks the live offer and settles after a second countdown, and after a block skips that offer and searches again.
- `/settle` accepts `{ "trigger": "agent" | "user" }`. Agent-triggered settlement returns 403 unless the stored autonomy allows the held amount. Missing session or approval means the safest mode.
- "What your agent did" report with a count of your actions versus the agent's.

**AI**
- `/api/evidence/extract`: reads seller listing text and returns quoted facts. Server-side validation (quote must appear in the text, field allowlist, numeric range, instruction rejection). Results are labelled seller-stated.
- Prompt-injection scanner (`scanUntrustedText`) and a live security test that appends a hostile instruction to the real listing.

**Core (tested)**: `autonomy.ts`, `untrusted-text.ts`. 112 tests in total.
