# M0.18 · Agent gateway, MCP server, real-data tooling, deployment

**Agent credential (new)**
- Agent keys (`ppk_...`): created by the shopper, bound to one approved Pact, 24 h expiry, revocable, stored as a SHA-256 hash only (`pactpay_agent_keys`). `POST/DELETE/GET /api/agent-keys` (browser session).
- Agent gateway `/api/agent/v1/*` (Bearer key): `rules`, `shortlist`, `hold`, `settle`, `orders/[id]`. The gateway always acts as the agent, never the user, so the shopper's autonomy limit is enforced server-side for any agent holding a key. It reuses the app's own routes, so approval binding, seller simulation and the settlement gate apply unchanged.
- `scripts/mcp-server.mjs`: dependency-free MCP (stdio) server exposing five tools over the gateway.
- `scripts/agent-redteam.mjs`: tries to break the guardrails and exits non-zero if any attack succeeds.
- UI: "Connect your own AI agent" panel; "For AI platforms" page.

**Real data**: `scripts/drift-watch.mjs` and `scripts/drift-report.mjs` measure how often live offers change price or stock (analysis tested). `docs/REAL-DATA.md`.

**Deployment**: `apps/web` now has a `start` script; `/api/health`; `render.yaml`; `RENDER_EXTERNAL_URL` fallback for the PayPal return URL; `docs/DEPLOY-RENDER.md`.

127 core tests.
