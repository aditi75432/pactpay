# PactPay brand kit

**Mark:** a bold "P" whose counter holds a lime dot: the payment, held. **Wordmark:** "Pact" in forest, "Pay" in green (lime on dark), set in Bricolage Grotesque and converted to outlines so it renders the same everywhere. Body text is Inter.

| File | Use |
|---|---|
| `pactpay-mark.svg` | App icon, favicon, avatars (tile included) |
| `pactpay-mark-plain.svg` / `-plain-light.svg` | The P without the tile, for light / dark backgrounds |
| `pactpay-logo.svg` | Mark + wordmark on light backgrounds |
| `pactpay-logo-light.svg` | Mark + wordmark on dark backgrounds |
| `devpost-thumbnail-3x2.png` | Devpost project thumbnail (3:2). Upload this as the project image |
| `video-end-card-1080p.png` | Last 3 seconds of the demo video |

Colours: forest `#10261D`, green `#1B6A47`, lime `#C9F55B`, paper `#F7F5EF`, cream `#F7F3E8`.
Fonts are self-hosted from `apps/web/app/fonts/` (SIL Open Font License, see `OFL.txt` there).
The same assets live in `apps/web/public/brand/` (served by the app), `apps/web/app/icon.svg`, `apple-icon.png` and `opengraph-image.png` (link previews), and `extension/icons/`.
